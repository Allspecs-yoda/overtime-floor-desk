# EAP $684/week is back

The 2024 Part 541 salary-level increase was vacated. DOL’s 2026-05-14 technical amendment (91 FR 27833) restored the 2019 thresholds: **$684/week** ($35,568/year) and HCE **$107,432**.

```bash
python3 desk/quote.py --exempt --salary-weekly 650
python3 desk/quote.py --exempt --salary-weekly 900
python3 desk/quote.py --exempt --salary-weekly 700 --hourly 27.00
```

$650/week fails the federal salary test even if the person has a manager title. $900/week clears federal and still fails CA/WA/NY/CO/AK — see `state-eap-floors.md`. Duties test is not evaluated here.

Not wage-and-hour advice.
